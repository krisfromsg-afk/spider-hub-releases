## Cài trên macOS
1. Mở `SpiderHub-macOS.dmg`, kéo **Spider Hub** vào thư mục **Applications** (cập nhật: chọn **Thay thế** — license, tài khoản, video giữ nguyên).
2. Lần mở đầu nếu macOS báo *"không xác minh được nhà phát triển"*: vào **Cài đặt hệ thống → Quyền riêng tư & Bảo mật**, kéo xuống, bấm **Vẫn mở (Open Anyway)**, rồi mở lại.
3. Đọc và đồng ý **Điều khoản sử dụng** là dùng được (bản Free không cần key).

## Kiểm tra file (tuỳ chọn)
Mỗi bản có file `.sha256` kèm theo. Trên macOS: `shasum -a 256 SpiderHub-macOS.dmg` — kết quả phải trùng nội dung file `.sha256`.
